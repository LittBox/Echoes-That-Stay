# Echoes that stay
Some words stay. This is where I keep them.

Echoes That Stay is my collection of words that linger long after a chat show ends — the lines I don’t want to lose, and the ones I return to when I need to recharge.
有些话，听完很久，依然有回声。

这里是回声收集站，收藏那些在访谈节目结束后，仍在我脑海里回响的话。有时记得意思，却想不起原句，于是把它们留在这里。等需要一点力量的时候，再回来读一读。

灵感来源：最近喜欢上了看访谈类节目，尤为爱看 @鲁豫老师 主持的一些节目，我每次都会听完，每次听完，有一些印象很深的话，我知道有这么一句话，我只能说出它的意思，但是无法准确的还原，再去视频里翻找，时间又不允许，于是，Echoes That Stay项目孕育而生，
项目中文名：回声收集站（from doubao）
项目英文名：Echoes that stay（from gpt）
> 起名字这件事情还怪有意思的，我用了doubao、deepseek、gpt，最终选择了这两个
